帮助 · 语法手册
语法手册，按由浅入深排列；每级都给一段能直接跑的例子。
例子基于「设置 → 数据 → 载入示例数据」之后的 departments / employees； 点上面的编号可以跳到对应段落。PG 协议端口默认 6432，psql / Navicat / DBeaver 可直连。
1
建表与增删改查
最小闭环：建表 → 插数据 → 查 → 改 → 删。
CREATE TABLEINSERTSELECTUPDATEDELETE
CREATE TABLE t (id serial PRIMARY KEY, name text, n int);
INSERT INTO t (name, n) VALUES ('a', 1), ('b', 2);
SELECT * FROM t;
UPDATE t SET n = n + 1 WHERE name = 'a';
DELETE FROM t WHERE id = 2;
2
查询：筛选、排序、分页、去重
日常用得最多的一层，条件、排序、翻页、去重都在这里。
WHEREAND / OR / NOTINBETWEENLIKE / ILIKEIS NULLORDER BY ASC/DESC NULLS FIRST|LASTLIMIT / OFFSETDISTINCT
SELECT DISTINCT dept_id FROM employees
WHERE salary BETWEEN 10000 AND 30000 AND name LIKE '张%'
ORDER BY salary DESC NULLS LAST
LIMIT 10 OFFSET 20;
3
分组统计
聚合函数配 GROUP BY；分组后再筛选用 HAVING（不是 WHERE）。
count / sum / avg / min / max（含 DISTINCT）· GROUP BYHAVING
SELECT dept_id, count(*) AS n, round(avg(salary), 2) AS avg_pay
FROM employees
GROUP BY dept_id
HAVING count(*) > 1
ORDER BY n DESC;
4
多表连接
LEFT JOIN 保留左表全部行，对不上的右表列为 NULL —— 统计「没人/没单」时靠它。
INNER / LEFT / RIGHT / CROSS JOINON表别名与列别名括号联接组 (a JOIN b ON …) x
SELECT d.name, count(e.id) AS n
FROM departments d
LEFT JOIN employees e ON e.dept_id = d.id
GROUP BY d.name
ORDER BY n DESC;
5
子查询与集合运算
标量子查询返回单值，可以引用外层列；WITH 把中间结果命名一次，多处复用。
标量子查询IN (子查询)EXISTSFROM 派生表 (SELECT …) xVALUES (…),(…)UNION [ALL] / INTERSECT / EXCEPTWITH
SELECT name FROM employees
WHERE dept_id IN (SELECT id FROM departments WHERE budget > 100000)
  AND salary > (SELECT avg(salary) FROM employees);

WITH big AS (SELECT id FROM departments WHERE budget > 100000)
SELECT count(*) FROM employees WHERE dept_id IN (SELECT id FROM big);
6
写入进阶：返回、冲突、批量
ON CONFLICT 是「有就改、没有就插」；RETURNING 直接拿到写后的行，省一次查询。
RETURNINGON CONFLICT DO NOTHING | DO UPDATE SET … EXCLUDEDINSERT … SELECTUPDATE … FROMDELETE … USING写语句的 WHERE/SET/VALUES 里也能用子查询
INSERT INTO employees (id, name, salary) VALUES (1, '张伟', 42000)
ON CONFLICT (id) DO UPDATE SET salary = EXCLUDED.salary
RETURNING id, name;

UPDATE employees e SET salary = s.salary
FROM (VALUES (1, 50000)) s(id, salary)
WHERE e.id = s.id RETURNING e.id, e.salary;
7
表结构与索引
索引是内存 B+Tree，建完立刻生效；等值、范围、IN、ORDER BY 免排序都会用到。
ALTER TABLE ADD / DROP / RENAME COLUMNRENAME TOALTER COLUMN TYPECREATE [UNIQUE] INDEXDROP INDEXPRIMARY KEY / UNIQUE / NOT NULL / DEFAULT / CHECK / FOREIGN KEYGENERATED AS IDENTITYCOMMENT ONTRUNCATE
ALTER TABLE employees ADD COLUMN email text;
CREATE INDEX idx_emp_dept ON employees (dept_id);
COMMENT ON TABLE employees IS '员工表';
TRUNCATE TABLE employees;
8
事务与并发
表级 S/X 锁、严格两阶段封锁（可串行化）；SAVEPOINT 用于部分回滚，ORM 的嵌套事务靠它。
BEGIN / START TRANSACTION（ISOLATION LEVEL …、READ ONLY）· COMMITROLLBACKSAVEPOINT / ROLLBACK TO SAVEPOINT / RELEASE SAVEPOINT
BEGIN;
UPDATE employees SET salary = salary + 100 WHERE id = 1;
SAVEPOINT sp1;
DELETE FROM employees WHERE id = 2;
ROLLBACK TO SAVEPOINT sp1;   -- 只撤销上面那条 DELETE
COMMIT;
9
常用函数与类型
够覆盖大部分报表写法；序列函数只在 SERIAL 建出的序列上有效。
字符串 lower / upper / length / trim / replace / substring / position / concat / string_agg日期 extract / date_part / date_trunc / now序列 nextval / currval / lastval其他 coalesce / nullif / greatest / least / regexp_matches类型 int / bigint / serial / numeric(p,s) / real / double precision / text / varchar(n) / boolean / date / timestamp
SELECT extract(year FROM now()) AS y,
       date_trunc('month', now()) AS m,
       coalesce(nullif(title, ''), '未填') AS t,
       round(avg(salary), 2) AS avg_pay
FROM employees
GROUP BY 1, 2, 3;
