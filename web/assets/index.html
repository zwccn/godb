每个库是独立的一套（自己的表、索引、WAL 与事务），库之间不能互相查询。 默认库不可删除；当前库需要先切走才能删；库内还有进行中的事务时也不能删。

示例查询（点一下填进编辑器）
支持的语法
查询
  • SELECT · WHERE · ORDER BY · LIMIT / OFFSET · DISTINCT
  • GROUP BY · HAVING · 聚合 count/sum/avg/min/max（含 DISTINCT）
  • INNER / LEFT / RIGHT / CROSS JOIN，多表串联、表别名与列别名
  • 标量子查询、FROM 子查询（派生表）、UNION / INTERSECT / EXCEPT、WITH
  • 集合函数 FROM generate_series(a,b) / regexp_matches(...)、数组下标 a[i]
  • CASE WHEN · CAST/:: · IN · BETWEEN · LIKE/ILIKE · ||
写入与结构
  • INSERT ... VALUES / INSERT ... SELECT · UPDATE · DELETE · RETURNING
  • CREATE / ALTER / DROP TABLE · TRUNCATE
  • CREATE INDEX（B+Tree）、主键 / 唯一 / 非空 / 外键 / 默认值
  • BEGIN · COMMIT · ROLLBACK（表级 S/X 锁，可串行化）
  • CREATE / DROP DATABASE，换库用顶栏的「库」下拉
工具
  • EXPLAIN / EXPLAIN ANALYZE 看计划与真实耗时
  • CHECKPOINT / FLUSH 立即落盘并轮转 WAL · SHOW 看参数
  • pg_catalog / information_schema 可供 psql、Navicat 查询
明确不支持
  • 递归 CTE（WITH RECURSIVE）、窗口函数
  • FULL JOIN / NATURAL JOIN、行级锁
  • IN (...) / EXISTS (...) 里的子查询
快捷键与小技巧
Ctrl+Enter 执行 Ctrl+Space 唤出补全 Esc 关掉补全 / 弹窗 拖编辑器底边改高度，双击恢复自动 弹窗可拖标题栏移动、拖右下角改大小，双击标题栏复位
补全会按当前库的真实表和列提示，带类型与主键标记
